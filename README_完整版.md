# 会议待办质检器

> 第九届传智杯大学生数智创新与AI应用大赛 · 赛道：办公协同与组织效率
> 参赛形式：单人　｜　提交日期：2026-11-25

## 一句话定位

不是又一个会议纪要工具，而是**纪要生成之后的一道质检**——判断 AI 提取的待办准不准、缺不缺、能不能直接建进任务系统。

**核心结论：AI 从会议里提取的待办，一半以上不能直接用。**（第 1 组实测：11 条里可直接执行 6 条，54.5%）

## 三组语料，三句话

| 组 | 语料 | 关键数字 | 说明什么 |
|---|---|---|---|
| 1 | 产品运营周会（本方构造，1,211 字） | 可直接执行 6/11（54.5%）→ 修正后 13/14 | 机制能跑通 |
| 2 | 国新办发布会实录（财政部官网，5,059 字符） | D 8/9；A 候选 5 条**成立 0 条** | 规则会误报，且每条误报可解释 |
| 3 | VCSum 真实会议 ASR（ACL 2023，4,913 字） | 28 场抽样**内部分工例会 0 场**；三要素齐全 0/145 句 | 公开语料承载不了这项验证 |

- **D 维度（原文依据逐字匹配）跨三组稳定在 90% 左右**——它是字符串匹配，不受语料类型影响。
- **A 维度（按人切片查遗漏）成立率从 100% 掉到 0**——同一份脚本一行没改，差别只在语料里有没有"人名 + 指派"。
- **公开能拿到的中文会议语料，恰好是待办密度最低的那一类**。能验证的语料，恰好是拿不到的那一类。

## 演示页怎么用

1. 双击 `index.html`（无需服务器、无外链、不联网）。
2. 在「试一试：把任意转录粘进来」里点 **载入示例转录**，或粘贴自己的会议转录。
3. **核对原文依据（D）**：逐条检查待办的"原文依据"能否在转录里逐字找到。示例数据 25 条依据命中 24 条，只有生成版 #3 不匹配（报告里作为 D 维度的真实样本保留）。
4. **查遗漏候选（A）**：按人切片重扫，输出"表里没有、但某人被派了活"的候选。示例数据输出 4 条候选，与 Python 版逐条一致。

**A 通道需要转录里有「参会人：」行**——它靠名单确定"谁被点名"。缺这一行时 A 通道不启动，D 通道不受影响。

边界提示：A 通道只输出**候选**，不下"遗漏"结论。候选要不要采纳，由人裁决。

## 复现方式

```bash
# D 通道 + A 通道（Python 版，命令行）
python qc_tools.py 会议转录_产品运营周会_示例.txt --demo

# A 通道前端实现与 Python 版对拍
node test_parity.js

# 组织视角：按人聚合负载、风险排序、补字段队列
python org_view.py 会议待办_修正版_v1.1.csv

# 双人标注一致率
python agreement.py 双人标注_标注员A.csv 双人标注_标注员B.csv
```

环境要求：Python 3（仅标准库）、Node 可选（仅用于 JS/Python 对拍）。

## 它在哪里不适用（写在这里，而不是等被问）

- **适用于**：有人被点名、有事被分派的内部分工会议。
- **不适用于**：对外发布会、论坛、沙龙、学术分享——这些语料里没有"谁什么时候做什么"。
- 第 2 组暴露的硬伤：责任主体是机构（"财政部／我们"）时，按人切片直接失明（郭婷婷 12 句零候选）。
- 第 3 组暴露的硬伤：真实 ASR 数据的说话人标签是**段落级**（40 个标签覆盖 145 句，约 27% 粒度），会让切片整体失真；ASR 错字（"哑剧"应为"牙具"）会让逐字引用把噪声固化进证据链。
- **数据性质**：第 1 组为构造语料（人物虚构），用于演示方法；真实内部会议的召回率与字段准确率**尚未验证**，验证设计与工具已备好（见附录 B.6）。

### 如果链接失效，怎么重新上线

**方式 A · 网页直接上传（4 步）**

1. 打开 `https://github.com/cbc080303/baiduai`；
2. 点 `uploading an existing file`，把 `index.html` 拖进去，点 `Commit changes`；
3. `Settings` → `Pages` → Source 选 `Deploy from a branch`，**Branch 下拉手动改成 `main`（默认是 `None`，这是最常踩的坑）**，目录 `/ (Root)` → `Save`；
4. 约 1 分钟后访问 `https://cbc080303.github.io/baiduai/`。

**方式 B · 用 token 走 API（无需浏览器点击）**

把有 `repo` 权限的 token 存到同目录 `.token` 文件，执行 `python open_pages.py`，脚本会开通 Pages 并轮询验证站点，用完请删除 `.token` 并撤销 token。

**方式 C · 百度秒哒 / 飞书妙搭**：在平台上新建应用，把 `index.html` 内容作为静态页面发布，取得平台链接。适合比赛要求"平台内可访问"的场景。

**方式 D · 不托管**：直接提交 `index.html` 附件，答辩现场本地双击打开。演示页零外链，断网也能跑——这反而是它最稳的地方。

**答辩前建议**：把线上地址与本机各打开一遍，确认按钮、表格横向滚动、窄屏布局正常；再截一张运行图，防止现场网络问题。

## 两个口径，不要混用

- **可直接执行 13/14**（报告 v1.2）：指字段齐全（动作/责任人/截止/依据四要件），不等于内容正确。
- **可直接建单 7/14**（组织视图）：指能直接建进任务系统。
- 这两个数定义不同，答辩被问到时必须分开说，否则会被认为前后矛盾。
